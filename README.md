# xkelib

Thanks to everyone who contributed and to everyone who made me glad I created this by actually using it!

## about 

This is a library of clean room hand made and assembly verified headers and import library for Xbox 360's official OS's kernel and xam API. 

This project represents years of work, and I'm sad to say those who encouraged and helped me the most are no longer with us.

_RIP. Anthony and Nate_ you are missed <3
